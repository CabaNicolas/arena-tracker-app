# Arena Tracker

Estadísticas del modo Arena de League of Legends: qué campeones, aumentos e ítems
rinden mejor, a partir de partidas públicas. App de escritorio para seguir tu
progreso y mejorar tu propio juego.

**Descargar:** https://github.com/CabaNicolas/arena-tracker-app/releases/latest

**Sitio:** https://cabanicolas.github.io/arena-tracker-app/

## Verificar la descarga

Cada versión publica el hash SHA-256 del instalador en las notas del Release.
Para comprobar que el archivo no fue alterado, en PowerShell:

```powershell
Get-FileHash .\Arena-Tracker-Setup.exe -Algorithm SHA256
```

El resultado debe coincidir con el hash de la versión. Si no coincide, no lo abras.
